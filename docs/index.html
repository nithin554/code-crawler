Why a graph

Grep can find a string. It can't answer a graph question.

“Who transitively calls this method?” “What breaks if I change this interface?” “What does the framework invoke that no source line calls?” Those are traversals, not searches. Code-Crawler builds the graph once and answers them with bounded recursive SQL.

⇄ Call tracing

Transitive callers, callees, and shortest paths — with call-site lines and resolution confidence on every edge.

◈ Virtual dispatch

Interface and base-class calls fan out to every real override in the project, so traces follow runtime targets, not just source text.

⚡ Run-time wiring

Routes, injected dependencies, and reflective lookups become first-class edges — including AspectJ and Spring AOP pointcuts woven into traces as INTERCEPT hops.

@ Decorators

Annotations are first-class nodes. Query @Transactional, @Cacheable, @Async, or your own custom decorator across types, methods, and fields.

▲ Analytics

Rank hotspots by fan-in, fan-out, and advice count. Surface dead-code candidates with the reason each symbol is unreachable.

▣ One SQLite file

Persistent, idempotent, file-scoped indexing. No server, no docker, no external database — just index.db.

Architecture

Parse once. Query forever.

A crawl walks the project, parses each file, resolves call targets against a global type index, writes nodes and edges in a single transaction, then rebuilds the derived dynamic edges.

1 · Discover & parse

Tree-sitter WASM grammars for Java, Python, TypeScript and JavaScript extract modules, types, methods, constructors, fields, imports, modifiers, annotations and decorators.

2 · Resolve

A global TypeIndex plus scope heuristics infer receiver types from locals, parameters, fields, new T(), this, and super.

3 · Persist

Nodes and edges land in SQLite (WAL). Ids are stable FQNs; reparsing a file replaces only that file's slice.

source → tree-sitter → TypeIndex → resolver → SQLite graph → MCP tools

Derived: dispatch

Every overridable call target gains DYNAMIC_DISPATCH edges to each override found in the hierarchy index.

Derived: advice

Aspect advice is matched against all methods with an AspectJ pointcut matcher, producing ADVISES edges.

Derived: queries

Recursive CTEs power callers, callees, paths, execution traces, subgraphs, hotspots, and dead-code detection.

Quickstart

Indexed in three commands.

Install, point it at a project, and register the server with your MCP client. The database is created automatically on first crawl.

Install and build

Requires Node.js 20 or newer.

npm install
npm run build

Index a project

Re-run any time; the crawl is idempotent and refreshes changed files.

node dist/index.js crawl /absolute/path/to/your-project
node dist/index.js status

Register the MCP server

Add it to your MCP client configuration and restart the client.

{
  "mcpServers": {
    "code-crawler": {
      "command": "node",
      "args": ["/absolute/path/to/code-crawler/dist/index.js"]
    }
  }
}
